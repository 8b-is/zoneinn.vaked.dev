2 · the lanes

visuals

the ternary equalizer: every spectrum frame collapses to eight bands and quantizes to {−1, 0, +1} — rising, rest, falling. A band inside the threshold is a genuine zero, never guessed.

safe bluetooth

pure Rust, no unsafe FFI. Soundcore Select 4 GO ships first-class — recognized by name before any other speaker.

voice

SUNO OSS (Bark) speaks the station ident between tracks via bark-selfhost — unspoken when unconfigured, never fabricated.

agy

the antigravity ultra lane renders the ASCII now-playing card — the foobar2000-style visual beyond the equalizer.

3 · run it

# the ternary equalizer, offline — no audio device, no models
cargo run -- demo --seconds 30

# the dial, and the honest status of every lane
cargo run -- list

# tune a station (stream playback: next slice)
cargo run -- play radio.vaked.dev --bt "Soundcore Select 4"
